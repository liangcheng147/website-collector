## 完成内容

### 表现层统一（Task 1–9）

- 全量切换到 Naive UI 2.45.3；设置页四分区控件与关于页三组（应用信息 / 更新 / 诊断信息）重排
- 颜色唯一来源：`src/theme/palettes.ts` + `src/theme/tokens.ts`，无硬编码十六进制，禁用 `n-global-style`
- 分类树采用「引导线 + 缩进层级」（18–20px）
- 保留自绘 TitleBar / 外壳 / 站点拖拽；图标库仍为 `lucide-vue-next`；未引入 Tailwind
- 模板中不出现静态 `style="..."`（终审发现的唯一一处由 `ed6c16d` 改为 `.titlebar .brand`）

### 近期功能（Task 10–16）

- **重复链接**（10）：统一 URL 归一化、分组、保留/合并/标记；可见标签「重复」（`DUPLICATE_TAG`）；导入合并为 tags 并集且保留 `existing.note`，手动合并为 tags 并集且 note 追加
- **favicon**（11）：仅实现 `Site.faviconPath`，以 base64 data URL 加载；缓存 confinement + HTML 实体解码 + chunked 体积上限
- **检查策略**（12）：`autoCheck` / `checkInterval` 仅持久化 + UI，不做定时调度；新增 `check_site_once_cmd` / `api.checkSiteOnce` 作为主流程单次原语，旧 `check_site_cmd` 保留（内置一次重试），`check_sites_cmd` 为预留批量原语
- **批量整理**（13）：失效清理为单 modal（列出 dead + 二次确认 + 入回收站），不提供永久删除；SiteTable 检测态批量按钮保持隐藏
- **搜索筛选**（14）：关键词 + 分类 + 标签 + 状态 + 时间组合筛选，常用筛选存入 `localStorage`；排序增加名称/ID 稳定兜底与 `aria-sort`
- **备份**（15）：目录 `<data_dir>/backups/`，文件名 `backup-<毫秒>[-NN].json`；恢复前自动快照；保留最近 10；恢复走 store `replaceDataFromBackup` 清理状态
- **命令面板**（16）：Ctrl/Cmd+K 唤起，按名称/hint/keywords 简单包含匹配；↑/↓ 导航忽略 Alt/Ctrl/Meta，IME 组合态整体让位；重复链接并入「管理页」

## 关键裁定

- 采用 Subagent 驱动开发：实现用 `meitaun/LongCat-2.5`（高风险 `#high`），review/复审用免费模型且与实现异构，模型仅当轮临时传参
- Task 9「末级拐角仅 `:last-child` 生效」经真实渲染验证不成立，未按字面实现
- 整分支终审（`f88daf1..e543117`）由 iceman-free 与 nemotron-3.5-lightning-free 双模型复审，均为 READY WITH NITS；7 项设计偏差全部接受
- `.modal-content` 被报死代码为误报，实际由 `ManageCategories.vue` / `ManageTags.vue` / `CategoryNode.vue` 使用
- 版本号动态取自 `getVersion()`；作者与许可按 `LICENSE`
