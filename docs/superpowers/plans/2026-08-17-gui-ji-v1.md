# 归集 v1.0 视觉与便携存储 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把「网站收藏管家」正式版改造为「归集」：简约商务视觉 + 无边框自绘标题栏 + 便携固定式数据存储（exe 旁 `./data/`）。

**Architecture:** 三条线互不耦合。① Rust 数据层：`config.rs` 新增纯函数目录解析（exe 可写→exe旁data，否则回退系统目录），删除迁移相关命令。② 窗口：`tauri.conf.json` 设 `decorations:false` + `transparent:true`，新增 Rust 窗口控制命令，前端新建 `TitleBar.vue`。③ 前端：重写 `main.css` 变量与组件样式，更新 TopBar/Settings/StatusBar 与命名。

**Tech Stack:** Tauri 2 (Rust 2021, serde, tauri-plugin-opener), Vue 3 + Pinia + TypeScript, Vite, Vitest。

## Global Constraints

- 软件名「归集」（GJ），对外文案（窗口标题/顶栏/productName）一律「归集」，不再出现「网站收藏管家」。
- 主色 `#3B5BDB`（hover `#2F4EC0`、淡底 `#EAF0FF`）；背景 `#F7F8FA`；面板白；文字 `#1F2329`/`#6B7280`；边框 `#E5E7EB`/`#D4D9E2`；悬停 `#EEF1F6`；成功 `#16A34A`/`#15803D`；警告 `#F59E0B`/`#B45309`；错误 `#DC2626`。
- 圆角 6px / 10px / 999px；阴影 `0 1px 2px rgba(16,24,40,.06)`、浮层 `0 4px 14px rgba(16,24,40,.08)`。
- 字体系统无衬线 `"Segoe UI",-apple-system,"PingFang SC","Microsoft YaHei",sans-serif`；等宽 `Consolas,...`。
- 弹窗外层 `min(420px,92%)`、嵌套 `min(380px,92%)`、`max-height:calc(100% - 32px)` + `overflow:auto`。
- 侧栏固定 170px；窗口 1200×800、min 900×600；标题栏高 38px、窗口圆角 10px。
- 数据固定 exe 旁 `./data/websites.json`；无写权限回退系统用户目录；无「更改存储位置」、不做旧数据迁移。
- 不新增 npm / cargo 依赖。
- 所有命令：Rust 用 `cargo test --manifest-path src-tauri/Cargo.toml` 与 `cargo build --manifest-path src-tauri/Cargo.toml`；前端用 `npm test` 与 `npm run build`。

/// exe_dir 可写时用 exe 旁 data/（便携），否则回退系统用户目录。
/// 返回 (数据目录, 是否回退)。
pub fn resolve_data_dir(exe_dir: &Path, app_data_dir: &Path, exe_writable: bool) -> (PathBuf, bool) {
    if exe_writable { (exe_dir.join("data"), false) } else { (app_data_dir.to_path_buf(), true) }
}

/// 探测目录是否可写：尝试创建探针文件再删除。
pub fn exe_dir_writable(exe_dir: &Path) -> bool {
    let probe = exe_dir.join(format!(".write_probe_{}", std::process::id()));
    match fs::write(&probe, b"") {
        Ok(_) => { let _ = fs::remove_file(&probe); true }
        Err(_) => false,
    }
}
```

fn exe_dir() -> std::path::PathBuf {
    std::env::current_exe()
        .ok()
        .and_then(|p| p.parent().map(|d| d.to_path_buf()))
        .unwrap_or_else(|| std::path::PathBuf::from("."))
}

fn resolve(app: &tauri::AppHandle) -> (std::path::PathBuf, bool) {
    let app_dir = app.path().app_data_dir().unwrap_or_else(|_| std::path::PathBuf::from("."));
    config::resolve_data_dir(&exe_dir(), &app_dir, config::exe_dir_writable(&exe_dir()))
}

fn active_data_dir(app: &tauri::AppHandle) -> std::path::PathBuf {
    resolve(app).0
}
```

```rust
#[derive(serde::Serialize)]
#[serde(rename_all = "camelCase")]
pub struct DataLocation { pub dir: String, pub is_fallback: bool }

#[tauri::command]
pub fn get_data_location(app: tauri::AppHandle) -> DataLocation {
    let (dir, fallback) = resolve(&app);
    DataLocation { dir: dir.to_string_lossy().to_string(), is_fallback: fallback }
}

#[tauri::command]
pub fn open_data_dir(app: tauri::AppHandle) -> Result<(), String> {
    let dir = active_data_dir(&app);
    let _ = std::fs::create_dir_all(&dir);
    tauri_plugin_opener::open_path(dir, None::<&str>).map_err(|e| e.to_string())
}

fn main_window(app: &tauri::AppHandle) -> Result<tauri::WebviewWindow, String> {
    app.get_webview_window("main").ok_or_else(|| "主窗口不存在".to_string())
}

#[tauri::command]
pub fn minimize_window(app: tauri::AppHandle) -> Result<(), String> {
    main_window(&app)?.minimize().map_err(|e| e.to_string())
}

#[tauri::command]
pub fn toggle_maximize_window(app: tauri::AppHandle) -> Result<(), String> {
    let win = main_window(&app)?;
    let result = if win.is_maximized().unwrap_or(false) { win.unmaximize() } else { win.maximize() };
    result.map_err(|e| e.to_string())
}

#[tauri::command]
pub fn close_window(app: tauri::AppHandle) -> Result<(), String> {
    main_window(&app)?.close().map_err(|e| e.to_string())
}

#[tauri::command]
pub fn is_maximized(app: tauri::AppHandle) -> bool {
    main_window(&app).map(|w| w.is_maximized().unwrap_or(false)).unwrap_or(false)
}
```

async function toggleMax() {
  maximized.value = !maximized.value
  document.documentElement.classList.toggle('win-maximized', maximized.value)
  await api.toggleMaximizeWindow()
}
function onDblClick() { toggleMax() }
</script>

      <span class="min" @click="api.minimizeWindow">—</span>
      <span class="max" @click="toggleMax">{{ maximized ? '❐' : '□' }}</span>
      <span class="close" @click="api.closeWindow">✕</span>
    </div>
  </header>
</template>
