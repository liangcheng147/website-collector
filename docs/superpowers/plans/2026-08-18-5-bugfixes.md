### Task 1：修复主页拖拽（dragstart 不触发）

**Files:**
- Modify: `src/components/SiteTable.vue`
- Verify: `npm run build`

**Interfaces:**
- Consumes: `props.sites` (SiteWithCategory[])，`store.openSite(id)`
- Produces: `<td>` 带 `draggable="true"` + dragstart/dragend 事件

- [ ] **Step 1：把 draggable 从 `<tr>` 移到第一个 `<td>`**

打开 `src/components/SiteTable.vue`，找到 `<tr>` 上的 `draggable="true"`，移除它。

找到第一个 `<td>`（网站名/链接列），加上 `draggable="true"`。

将 `@dragstart`、`@dragend` 事件从 `<tr>` 移到该 `<td>`。

修改前：
```html
<tr
  draggable="true"
  @dragstart="onDragStart($event, s)"
  @dragend="onDragEnd"
  @click="onRowClick($event, s)"
>
```

修改后：
```html
<tr @click="onRowClick($event, s)">
  <td
    class="link-cell"
    draggable="true"
    @dragstart="onDragStart($event, s)"
    @dragend="onDragEnd"
  >
```

- [ ] **Step 2：运行构建验证**

Run: `npm run build`
Expected: BUILD SUCCESS

- [ ] **Step 3：提交**

```bash
git add src/components/SiteTable.vue
git commit -m "fix: 将 draggable 从 tr 移到 td 修复 Chromium 拖拽不生效"
```

### Task 3：侧边栏分类折叠

**Files:**
- Modify: `src/store/app.ts`（settings 类型 + toggle action）
- Modify: `src/components/CategoryNode.vue`（箭头 + 折叠逻辑）
- Modify: `src/styles/main.css`（箭头样式）
- Verify: `npm run build`

**Interfaces:**
- Consumes: `store.settings.collapsedCategories` (number[])
- Produces: `store.toggleCategoryCollapse(id: number)`

- [ ] **Step 1：在 store app.ts 的 settings 类型中添加 collapsedCategories**

找到 `settings` 的类型定义（`Settings` 接口或内联类型），添加字段：

```typescript
collapsedCategories: number[]
```

在 store 的 state 初始化中，给 settings 加默认值：

```typescript
collapsedCategories: [],
```

- [ ] **Step 2：在 store 添加 toggleCategoryCollapse action**

在 store 的 actions 中添加：

```typescript
toggleCategoryCollapse(id: number) {
  const idx = this.settings.collapsedCategories.indexOf(id)
  if (idx === -1) {
    this.settings.collapsedCategories.push(id)
  } else {
    this.settings.collapsedCategories.splice(idx, 1)
  }
},
```

- [ ] **Step 3：修改 CategoryNode.vue 添加折叠箭头**

在 CategoryNode.vue 的 `<template>` 中，找到显示分类名的 `<span class="name">`，在其前面加一个折叠箭头：

```html
<span
  v-if="node.children.length > 0"
  class="collapse-arrow"
  @click.stop="store.toggleCategoryCollapse(node.id)"
>{{ store.settings.collapsedCategories.includes(node.id) ? '▶' : '▼' }}</span>
```

然后包裹子分类列表的 `<div class="children">`，加上 `v-show`（箭头已有 `v-if` 判断子分类，这里只用 `v-show` 切换可见性）：

```html
<div class="children" v-show="!store.settings.collapsedCategories.includes(node.id)">
```

- [ ] **Step 4：在 main.css 添加箭头样式**

```css
.collapse-arrow {
  display: inline-block;
  width: 14px;
  text-align: center;
  cursor: pointer;
  color: var(--text-2);
  font-size: 10px;
  flex-shrink: 0;
}
.collapse-arrow:hover { color: var(--text-1); }
```

- [ ] **Step 5：运行构建验证**

Run: `npm run build`
Expected: BUILD SUCCESS

- [ ] **Step 6：提交**

```bash
git add src/store/app.ts src/components/CategoryNode.vue src/styles/main.css
git commit -m "feat: 侧边栏分类支持展开/收起子分类"
```
