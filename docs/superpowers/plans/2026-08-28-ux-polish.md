# UX 优化 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 修复站点归集应用的前端交互缺陷（吸顶工具条、侧栏分区、树形全局展开/收起、标签选择器、回收站确认、表单校验、空状态文案、表头排序、列表键盘流），提升日常使用流畅度与安全性，不改 Rust 后端。

**Architecture:** 纯前端改动。状态与逻辑统一在 Pinia store（`src/store/app.ts`）；可复用 UI 抽成新组件 `TagInput.vue`；样式集中在 `src/styles/main.css`；交互行为尽量下沉到 store 以保证可测试。每个改动配套 vitest 单测或组件测试，CSS/视觉类改动以 `npm run build` + 手动验证收口。

**Tech Stack:** Vue 3 `<script setup>` + TypeScript、Pinia、Vitest + @vue/test-utils（jsdom）、Vite、Tauri 2（本次不改 Rust）。

## Global Constraints

- 仅前端改动，**不修改 `src-tauri/` 任何文件**，不新增/改名 `invoke` 命令（`src/api.ts` 契约保持不变）。
- 应用窗口为无边框 + 透明（`decorations:false`、`transparent:true`），改样式时注意透明背景，不破坏手写标题栏。
- Vite 固定端口 **1420**（`strictPort:true`），本地 `npm run dev` / `tauri dev` 依赖此端口，不要改。
- 测试/校验命令：`npm test`（vitest，含 `src/store/app.spec.ts`）、`npx vue-tsc --noEmit`（类型检查）、`npm run build`（先 `vue-tsc` 再 `vite build`）。每次提交前至少跑通 `npm test` 与 `npm run build`。
- 保留现有全局 `Esc` 行为（`App.vue` 中 Esc 关弹窗 + 清选择），新增快捷键不得与之冲突。
- UI 文案用简体中文（见 spec 验收文案）。
- 保持现有能力不回退：全选复选框、`Ctrl/Shift` 多选、`selectRange`、`selectAllVisible` 等。

`src/components/TagInput.vue`：
```html
<script setup lang="ts">
import { ref, computed } from 'vue'
const props = defineProps<{ modelValue: string[]; available: string[] }>()
const emit = defineEmits<{ (e: 'update:modelValue', v: string[]): void }>()
const text = ref('')
const open = ref(false)
const lowerSel = computed(() => new Set(props.modelValue.map(t => t.toLowerCase())))
const filtered = computed(() => {
  const q = text.value.trim().toLowerCase()
  return props.available.filter(t => !lowerSel.value.has(t.toLowerCase()) && (q === '' || t.toLowerCase().includes(q)))
})
function add(tag: string) {
  const t = tag.trim()
  if (!t) return
  if (props.modelValue.some(x => x.toLowerCase() === t.toLowerCase())) { text.value = ''; return }
  emit('update:modelValue', [...props.modelValue, t])
  text.value = ''
}
function onKey(e: KeyboardEvent) {
  if (e.key === 'Enter') { e.preventDefault(); if (filtered.value.length) add(filtered.value[0]); else add(text.value); }
  else if (e.key === 'Backspace' && text.value === '' && props.modelValue.length) {
    emit('update:modelValue', props.modelValue.slice(0, -1))
  }
}
function remove(tag: string) { emit('update:modelValue', props.modelValue.filter(x => x !== tag)) }
</script>

<template>
  <div class="tag-input">
    <span v-for="t in modelValue" :key="t" class="chip">{{ t }}<button class="chip-x" type="button" @click="remove(t)">×</button></span>
    <input v-model="text" @focus="open = true" @blur="open = false" @keydown="onKey" placeholder="选择或输入后回车新建" />
    <div v-if="open && filtered.length" class="tag-opts">
      <button v-for="t in filtered" :key="t" type="button" class="opt" @mousedown.prevent="add(t)">{{ t }}</button>
    </div>
  </div>
</template>
```

validateSite(name: string, url: string): string | null {
  if (!name.trim()) return '请填写名称'

const sortKey = state.sortKey
if (sortKey) {
  const dir = state.sortDir === 'asc' ? 1 : -1
  list = [...list].sort((a, b) => {
    const av = sortKey === 'status' ? a.status : (a as any)[sortKey]

toggleSort(key: 'name' | 'url' | 'status') {

  else if (this.sortDir === 'asc') this.sortDir = 'desc'
  else { this.sortKey = null; this.sortDir = 'asc' }
},

```ts
selectRelative(dir: 'up' | 'down') {
  const list = this.filteredSites
  if (!list.length) return
  const cur = this.selectedIds.length ? list.findIndex(s => s.id === this.selectedIds[this.selectedIds.length - 1]) : -1
  let next = dir === 'down' ? cur + 1 : cur - 1
  if (next < 0) next = 0
  if (next >= list.length) next = list.length - 1
  this.selectedIds = [list[next].id]
},
deleteSelectedToRecycle() {
  if (!this.selectedIds.length) return
  this.deleteSites([...this.selectedIds]) // 现有 deleteSites 已入回收站
  this.clearSelection()
},
```
