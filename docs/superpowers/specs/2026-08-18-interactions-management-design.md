# 归集 v1.2 交互与管理设计文档

日期：2026-08-18
状态：已确认，待实施

## 概述

本设计为「归集」添加交互与管理能力，共 24 项需求，分 9 个部分：选中交互、全选、打开网站按钮、主页面拖拽、管理页面（分类/标签）、侧边栏折叠、小窗口内容修复、主题下拉框、职责分工。

## 一、选中交互（主页面表格）

- **左键单击行** = 单选该行。
- **Ctrl+左键** = 追加选中 / 取消选中（支持非连续多选）。
- **Shift+左键** = 范围多选：从上次选中行到当前行之间的所有行被选中。
- **禁止拖选文字**：表格文字设置 `user-select: none`（桌面软件风格，去除网页式蓝底选字）。
- 已选数量显示在顶栏右侧（「已选 N 项」）。

## 二、全选

- 表格表头最左新增**总复选框**。
- 单击 = 全选当前视图（含搜索/分类筛选后的全部结果）所有网站；再次单击 = 全部取消。
- 全选后每行行首复选框均勾选。

## 三、打开网站按钮

- 每行的「链接」文字**后面紧跟一个打开按钮**（悬停该行时显示，移开隐藏）。
- 点击 = 用系统浏览器打开该网站链接。
- 不新增独立列。

## 四、主页面拖拽（4 种）

- **① 拖分类改层级**：侧边栏内拖一个分类到另一分类上 = 变成其子分类；拖到「全部」上方 = 提升为顶级分类。
- **② 拖网站改分类**：表格中按住一行拖到侧边栏某个分类上 = 该网站改归该分类。
- **③ 拖网站加标签**：表格中拖一行到侧边栏某个标签上 = 给该网站打上该标签。
- **④ 拖标签加网站**：侧边栏拖一个标签到表格某行上 = 给该行网站打上该标签。
- 拖拽过程中给出视觉反馈（拖起阴影 / 目标高亮 / 不可放置时禁用样式）。

## 五、管理页面

- 顶栏新增「管理」入口按钮，点击后内容区切换为**全屏管理视图**；左上「返回主页面」退出。
- 两个页签：**分类** / **标签**。
- 管理页面**不做拖拽**（拖拽统一在主页面）。

### 5.1 分类页签

- **批量添加分类**：左侧卡片，父分类下拉框（默认「（顶级分类）」，可选已有分类）+ 分类名输入框 + 「添加」按钮。逐个输入，可连续添加；选父分类时新建为其子分类。
- **批量删除分类**：右侧分类列表（缩进表示层级，显示网站数），勾选后点「批量删除所选」，弹**统一确认框**，一次选择：
  - 「移到未分类」：删除分类，其中的网站保留并归入「未分类」；
  - 「连同网站一起删除」：删除分类及其所有网站。
- 分类列表支持勾选多行。

### 5.2 标签页签

- **标签列表**：显示所有标签 + 各标签网站数。
- **重命名标签**：悬停标签行显示「✎」按钮，点击进入行内编辑，保存后全局生效。
- **删除标签**：勾选多个点「删除所选」，删除后相关网站的该标签被移除。
- **合并标签**：勾选 2 个以上点「合并所选」，输入目标标签名。目标为已有标签 = 归并进去；目标为新名字 = 创建新标签。这些标签打到的所有网站的标签统一替换为目标标签，被合并的标签自动消失（无网站再使用）。
- **批量加/去标签**：输入标签名 + 选择分类范围，一次性为范围内所有网站批量添加标签，或批量去除某标签。

## 六、侧边栏折叠

- 四个分组（分类 / 视图 / 标签 / 系统）均可折叠：点分组标题在展开（▼）/ 收起（▶）间切换。
- **折叠状态持久化**：保存至 settings.json，重启后保持。

## 七、小窗口不丢内容

- 侧边栏内容超出时**正确滚动**（修复底部被裁切问题）。
- **状态栏始终可见**：不被窗口缩小挤出（布局固定，状态栏常驻）。

## 八、主题设置

- 设置弹窗「主题」分区内，主题选择从 radio 改为**下拉框**。
- 三个选项：跟随系统 / 亮色 / 暗色。

## 九、职责分工（不重复建设）

- 保留现有功能入口：
  - 侧边栏右键：单分类重命名 / 删除 / 新建子分类；
  - 批量操作栏弹窗：移动分类 / 添加标签；
  - 右键菜单：单网站操作（编辑 / 删除等）。
- 管理页面只承担现有界面做不到的**批量 / 进阶操作**，不重复已有功能。

## 技术要点

- 前端：Vue 3 + Pinia，涉及 store 动作扩展（批量移动、批量加/去标签、合并标签、拖拽移动）。
- 后端：Tauri 2 Rust 命令扩展（批量分类/标签操作、设置项持久化）。
- 数据持久化：settings.json 新增侧边栏折叠状态字段。
- 拖拽：HTML5 Drag & Drop 或指针事件实现，注意与现有点击/选择逻辑不冲突。
- 兼容暗色主题（新 UI 元素使用 CSS 变量）。

## 测试要点

- 选中交互：左键 / Ctrl / Shift 组合、全选、跨搜索过滤后全选。
- 拖拽：4 种拖拽场景、无效放置、拖动取消。
- 管理页：批量添加（含父分类）、批量删除（两种处置）、标签重命名/删除/合并、批量加/去标签。
- 侧边栏折叠状态持久化：折叠后重启仍保持。
- 小窗口：窄/矮窗口下侧边栏与状态栏均可见。
