# 设计文档：归集 · 青绿色高级感风格方向

- 日期：2026-08-28
- 关联项目：`website-collector`（Tauri 2 + Vue 3 本地优先网站收藏桌面应用）
- 来源：经由 `ui-ux-pro-max` 检索的 Minimalism/Swiss 风格 + 用户从可视化伴侣中选定「方向 A · 现代高级感」，并改为技能库推荐的青绿色方案（teal #0D9488 + 橙色强调 #EA580C）。
- 状态：已与用户确认（风格 + 留白/描边力度均认可）。

## 1. 目标与范围

**目标**：在**不改变任何功能、结构、布局、内容**的前提下，仅刷新「归集」的视觉风格气质——配色、质感（描边/阴影）、字体排印与微动效——使整体更接近「现代高级感 / 生产力工具」的观感（类 Linear / Raycast 的克制、留白、精致）。

**属于本次范围（仅风格）**
- 更新 CSS 设计令牌（`:root` 与 `[data-theme="dark"]` 的变量值）。
- 修正少数几处写死旧靛蓝色相的地方（如 `.app` 背景径向渐变），使其跟随新令牌。
- 统一留白、圆角、描边与阴影的视觉节奏（通过令牌，而非改结构）。

**明确不属于本次范围（非目标 / 禁止改动）**
- ❌ 任何组件结构、DOM 层级、布局（栅格/间距分布/定位）变更。
- ❌ 任何功能、交互逻辑、数据流、IPC 命令变更。
- ❌ 窗口属性（`decorations`/`transparent`/`titlebar` 拖拽区）变更。
- ❌ 内容增删（文案、分类、字段）。
- ❌ 图标方案替换（沿用现有文本符号，不引入 SVG 图标集）。
- ❌ `src-tauri/`、`src/api.ts` 的任何修改。

> 约束来源：`AGENTS.md` 要求前端改动不得触及 Rust 后端与 `invoke` 契约；本任务纯属前端 CSS 令牌层。

## 2. 设计语言（原则）

- **瑞士极简 / Swiss Minimalism**：干净、克制、网格化、留白充足、高对比文字。
- **单一主色 teal** 承担所有交互态（选中、悬停、焦点、链接、主按钮）；**橙色 #EA580C 仅用于关键 CTA**（如「添加/保存」），避免多彩花哨。
- **细描边 + 克制阴影**：1px 浅色描边建立边界，阴影仅用于浮层（弹窗/菜单/上下文菜单），且透明度极低。
- **字体排印**：沿用项目既有 `Geist Variable`（`Inter` 同级，干净专业，已打包）；保持 14px 基准、1.55 行高。
- **可达性**：所有交互元素可见焦点环；文字对比度 ≥ 4.5:1；尊重 `prefers-reduced-motion`。

## 4. 组件风格映射（仅消费令牌，不改结构）

下列组件已通过 `var(--…)` 引用令牌，令牌更新后将自动获得新风格，无需改结构：
标题栏 `.titlebar`、顶栏 `.topbar`、侧栏 `.sidebar`（含分组/行/选中态）、站点表 `.site-table`（含选中行、悬停第二列着色、状态点）、状态栏 `.statusbar`、弹窗 `.modal`、管理页 `.manage-*`、标签输入 `.tag-input-wrap`/`.chip`、上下文菜单 `.ctx`、按钮 `.btn`/`.primary`/`.danger`、复选框 `.cb`、危险提示 `.err`。

**需顺手修正的写死色相（改为令牌/teal 透明）**：
- `.app` 背景径向渐变中的 `rgba(59,91,219,.05)` → 改用 teal 透明 `rgba(13,148,136,.05)`。
- 深色块中任何遗留的 `rgba(107,138,255,…)`（旧靛蓝环）统一改为新的 `--ring` 对应值（已由令牌驱动，按需替换字面量）。
- 深色主题 `.btn.primary` 文字色 `#0B0D12` 在亮 teal 上对比不足时可改为近黑青 `#06231F`（视实测对比度微调）。

> 以上均为「颜色值替换」，不增删 DOM、不改选择器层级、不动 `padding`/`margin` 的布局语义（仅按已确认力度统一令牌即可，不额外调整间距）。

## 5. 动效与可达性

- 沿用现有 150–250ms 过渡与 `prefers-reduced-motion` 媒体查询（保持不变）。
- 焦点环统一为 teal `--ring`；键盘可达、可见。
- 不引入新动画、不改动动画触发逻辑。

## 6. 涉及文件

- `src/styles/main.css` —— 唯一主要改动点（令牌值 + 极少数写死色相替换）。
- 不触碰任何其他 `.vue`、`.ts`、`src-tauri/`、`api.ts`。

## 7. 验收

- `npm run build`（含 `vue-tsc --noEmit`）通过。
- 既有 `npm test`（66 项）全部通过（令牌改动不影响逻辑）。
- 透明/无边框窗口下浅色与深色主题观感正常；手动用打包后的便携 `website-collector.exe` 抽查：标题栏、侧栏、表格、弹窗、管理页、标签输入、上下文菜单均呈现青绿色调，且功能/布局无任何变化。
- 对比度抽查：主文字/次文字在浅色与深色下均 ≥ 4.5:1。

## 8. 后续可选（不在本次）
