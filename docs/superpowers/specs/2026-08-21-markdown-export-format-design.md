# 设计文档：Markdown 导出改为无序列表项格式

- 日期：2026-08-21
- 状态：已批准（待实施）
- 范围：仅修改 `src-tauri/src/md.rs` 的 Markdown 导出与导入逻辑

## 1. 背景与问题

当前 `export_to_md`（`src-tauri/src/md.rs:3`）把每个站点导出为单行 Tab 分隔文本：

```
名称<TAB>网址<TAB>状态
> 备注
```

由于没有 Markdown 列表标记、也没有空行分隔，在多数 Markdown 查看器里多个站点会被渲染成同一段落内的软换行（等价于 Shift+Enter 的效果），条目之间没有真正分成独立的一行，可读性差。

目标：把每个站点导出为标准的无序列表项 `- [名称](网址) 状态`，使其在任意 Markdown 渲染器里都独占一行、清晰可辨。

## 2. 新导出格式

分类标题 `#` / `##` 层级保持不变。每个站点改为：

```
- [名称](网址) ✅ 2026-08-19T09:28:38.559Z
```

规则：
- 名称为 Markdown 行内链接：`[名称](网址)`
- 有检测记录时，状态标记（✅ 或 ❌ 加 `last_check` 时间）附在行尾，前加一个空格
- 无检测记录（`status` 为 `unknown` 且无 `last_check`）时，只输出 `- [名称](网址)`
- 备注保持放在条目下一行，使用块引用 `> 备注`；为与列表项对齐，前置两个空格缩进（`  > 备注`）

示例：

```
# Markdown 工具

- [blossom-editor/blossom](https://github.com/blossom-editor/blossom) ✅ 2026-08-19T09:28:38.559Z
  > A markdown editor that you can deploy on your own servers...

- [markdowm思维导图](https://github.com/markmap/markmap) ✅ 2026-08-19T09:28:39.840Z

- [妙言](https://miaoyan.app) ✅ 2026-08-19T09:28:40.961Z
  > 轻灵的Markdown 笔记本伴你写出妙言~
```

## 3. 导入逻辑变更（`import_from_md`，md.rs:34）

采用**方案 B**：导入只识别新的无序列表项格式，不再兼容旧的 Tab 分隔格式。

解析规则：
- 以 `#` 开头的行：分类标题，层级规则不变
- 以 `- `、`* ` 或 `+ ` 开头的列表项行：提取站点
  - 优先用 Markdown 链接语法 `[名称](网址)` 解析名称与网址
  - 若行内含 `](` 链接，则取链接文字为名称、括号内为网址
  - 若没有链接语法（纯文本），则整行作为名称、网址留空（与现状"无 url 则跳过"保持一致，网址为空时该站点不入库）
  - 行尾的状态标记（✅/❌ 及时间）忽略，导入后 `status` 置为 `unknown`、`last_check` 为 `None`（与现状一致）
- 以 `>` 开头的行（允许前置空格）：作为上一条站点的备注，绑定规则不变
- 旧的导出文件（Tab 分隔、无 `- ` 前缀）将无法被识别为站点，导入后这些站点会丢失——用户需重新导出一次

## 4. 边界与异常处理

- URL 含 `)` 或名称含 `]` 的极端情况：Markdown 链接语法会解析异常，但此类 URL 在实际收藏中极罕见，本期不专门处理（YAGNI）。若解析失败导致网址为空，该站点按现有规则跳过。
- 备注中的换行/制表符：导出时已 `replace('\n'/'r'/'t', " ")` 压成单行（现状逻辑保留）。
- 列表项与块引用之间的空行：导入解析按行处理、空行跳过，不影响结构。

## 5. 测试（md.rs 测试模块）

- 更新 `import_ignores_status_and_tags`：用新列表项格式文本验证导入忽略状态/标签、备注绑定正确
- 更新 `export_sanitizes_note_tabs_and_newlines`：备注仍压成单行、无 Tab
- 保留 `import_note_binding_stops_at_heading`，改用新格式文本
- 保留文件读写（导出/导入）两条用例，必要时微调文本

## 6. 不在范围内（YAGNI）

- 不改动 JSON 数据模型、分类树结构、UI 导出按钮逻辑
- 不兼容旧 Tab 格式导入
- 不引入新的配置项或导出选项
- 不改动状态检测、浏览器内核复核等其它模块

## 7. 验收标准

1. `cargo test` 全绿（md 模块用例更新后通过）
2. 导出的 .md 在常见 Markdown 查看器中每个站点独占一行、为无序列表项、名称为可点击链接
3. 导出的 .md 可重新导入，站点/分类/备注结构完整还原（状态重置为 unknown）
